# 数值类型名称

Kaula 源码的数值类型注解使用明确位宽名称：

- 有符号整数：`i8`、`i16`、`i32`、`i64`
- 无符号整数：`u8`、`u16`、`u32`、`u64`
- 浮点数：`f32`、`f64`

`int`、`uint`、`int32`、`uint8`、`float`、`double`、`byte` 等历史数值别称在源码类型注解中会报错，并给出对应名称。指针、数组、函数签名中的数值类型也遵循此规则。

`f8` 不是受支持的类型。8 位浮点数需要额外定义数值格式、运算和转换，不能当作 `f32` 的别称。

此规则针对源码中的数值类型拼写；`extern` 的 C ABI 声明与标准库内部元数据保留 C 类型。`bool`、`char`、`string` 等非数值类型仍然可用。用户定义的结构体、枚举和命名类型也仍然可用。
